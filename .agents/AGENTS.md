# Femazon Design Rule
- Keep the existing Femazon color palette.
- Improve only: Layout, Information hierarchy, Navigation, Ecommerce structure, Typography hierarchy, Spacing, Image presentation, Card consistency, Hover interactions, Mega menus, Responsive behavior.
- The final result should feel like: REVOLVE-style editorial fashion ecommerce structure + Femazon's own visual identity + Femazon Services + AI Wardrobe + Shopping Assistant.
- Do not make it look like a SaaS landing page.
- Do not use developer/demo labels such as "Day 3", "Module", "Authentication", or technical descriptions anywhere in the customer-facing homepage.
